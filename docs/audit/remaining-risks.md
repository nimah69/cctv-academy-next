# ریسک‌ها و محدودیت‌های باقی‌مانده

1. **رفتار مرورگر تأیید نشده است:** آزمون نحوی به‌تنهایی کلیک‌ها، جریان‌های کاربری یا محاسبات را تأیید نمی‌کند.
2. **PDF مرجع در مخزن نیست:** تطبیق دقیق شماره صفحه، نقل‌قول و اصالت محتوای منبع مسدود است.
3. **امنیت پویا به‌طور کامل ممیزی نشده است:** مسیر Subnet در آزمون تزریق HTML بررسی و تأیید شد؛ تعداد زیادی sink از نوع `.innerHTML` و handlerهای درون‌خطی همچنان نیازمند ردیابی داده هستند. آسیب‌پذیری کلی تأیید نشده است.
4. **آفلاین کامل اثبات نشده است:** فونت Google Fonts مشاهده شد؛ سایر وابستگی‌ها و حالت قطع اینترنت باید آزمایش شوند.
5. **حفظ داده نیازمند آزمون است:** چند کلید ذخیره‌سازی و پیشوند پیشرفت وجود دارد؛ هیچ کلیدی بدون آزمون مهاجرت تغییر نمی‌کند.
6. **انتشار عمومی فعال نیست:** مشخصات GitHub Pages غیرفعال است؛ لینک زنده تأیید نشده.
7. **داده‌های تعبیه‌شده پیچیده‌اند:** پیش از بازآرایی یا حذف کد، وابستگی‌ها و رفتار پایه باید ثبت شود.

این فهرست با اجرای آزمون‌های بعدی به‌روزرسانی می‌شود.
