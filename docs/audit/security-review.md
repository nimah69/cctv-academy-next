## دامنهٔ این بررسی
- بازبینی ایستای فایل اصلی `index.html` و بررسی مسیر ورودی IPv4 در محاسبه‌گر Subnet.
- افزودن آزمون Playwright برای ورودی شبیه HTML.
- مرور منابع خارجی و الگوی استفاده از HTML پویا.

این بررسی **ممیزی کامل امنیتی یا اثبات نبود XSS در کل برنامه نیست**.

## مشاهدات مستند
1. فایل اصلی یک HTML بزرگ با CSS، JavaScript، داده و چندین اسکریپت درون‌خطی است.
2. چندین استفاده از `.innerHTML` و handlerهای رویداد درون‌خطی وجود دارد. این موارد به‌تنهایی آسیب‌پذیری محسوب نمی‌شوند؛ باید منبع داده و نحوهٔ escaping هر مسیر بررسی شود.
3. منبع JavaScript خارجی در ویژگی `src` اسکریپت‌ها پیدا نشد. یک stylesheet خارجی از Google Fonts وجود دارد.
4. meta مربوط به Content Security Policy در HTML پیدا نشد. افزودن CSP سخت‌گیرانه در وضعیت فعلی می‌تواند به‌علت اسکریپت‌ها و handlerهای درون‌خطی عملکرد را بشکند؛ در این مرحله تغییری در سیاست امنیتی اعمال نشده است.
5. مسیر Subnet ورودی را از طریق `ipv4ToNumber` اعتبارسنجی می‌کند: چهار بخش عددی، هر بخش بین ۰ و ۲۵۵. مقادیر خروجی آدرس به شکل نرمال‌شده تولید می‌شوند، نه با بازتاب مستقیم رشتهٔ ورودی.

## آزمون اجراشده
- آزمون، رشته‌ای شبیه `<img src=x onerror="window.__xssAudit=1">` را در ورودی IPv4 قرار می‌دهد.
- معیار قبولی: handler اجرا نشود و خروجی محاسبه‌گر عنصر `img` نداشته باشد.
- پس از ورودی نامعتبر، یک IPv4 معتبر نیز وارد و خروجی شبکه بررسی می‌شود.
- نتیجه: PASS در [Browser smoke test، اجرا 39477398933](https://github.com/nimah69/cctv-academy-next/actions/runs/39477398933).
- Static quality check پس از تغییر: PASS در [اجرا 39477399015](https://github.com/nimah69/cctv-academy-next/actions/runs/39477399015).

## تصمیم و اقدامات بعدی
- در این مرحله هیچ sink یا قابلیت موجودی حذف نشده است.
- آزمون جدید به مجموعهٔ رگرسیون اضافه شد.
- باید ادامهٔ ردیابی داده برای محتوای ذخیره‌شده، متن‌های تعبیه‌شده، ورودی‌های ابزارها و سایر خروجی‌های `.innerHTML` انجام شود.
- آزمون Android/WebView واقعی، قطع کامل شبکه و ممیزی علمی با PDF همچنان جداگانه لازم‌اند.

**بازبینی جزئی انجام شد؛ آسیب‌پذیری XSS در مسیر آزموده‌شده مشاهده نشد.** این نتیجه به سایر مسیرهای برنامه تعمیم داده نمی‌شود.
