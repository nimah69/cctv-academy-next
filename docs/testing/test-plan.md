# برنامه آزمون

- [x] فهرست فایل‌ها و اندازه فایل اصلی.
- [x] استخراج بلوک‌های اسکریپت و کامپایل نحوی.

- [ ] اعتبارسنجی HTML/CSS با ابزار مستقل.

## سطح 2 — ساختار محتوا
- [ ] شمارش قطعی فصل‌ها، درس‌ها، سؤال‌ها، گزینه‌ها، پاسخ‌ها، کارگاه‌ها و محاسبه‌گرها.
- [ ] شناسایی سؤال بدون پاسخ معتبر یا با گزینه‌های تکراری.
- [ ] کشف تکرار لفظی و سپس بازبینی معنایی.
- [ ] تطبیق با PDF اصلی در صورت دسترسی.

## سطح 3 — رفتار مرورگر
- [ ] باز/بسته‌شدن منوها و پنجره کارگاه.
- [ ] پیمایش فصل، جست‌وجو، آزمون و مرور.
- [ ] ذخیره پیشرفت، reload، بازیابی، خروجی و ورود داده.
- [ ] اجرای مجدد و reset هر کارگاه.
- [ ] لمس/کلیک تکراری و ورودی نامعتبر.
- [ ] بررسی کنسول و خطاهای Promise.

## سطح 4 — محاسبه‌گرها
برای هر محاسبه‌گر: حالت معمول، صفر، منفی، خالی، غیرعددی، اعشاری، مرز بالا/پایین، تغییر یک ورودی، reset و مقایسه مستقل.
- PoE: توان PD/PSE، افت کابل، بودجه کل و محدودیت پورت.
- پهنای باند/ذخیره‌سازی: bitrate، روزها، ساعت ضبط، حاشیه‌ها، RAID و ظرفیت قابل استفاده.
- IPv4/Subnet/VLSM: /0، /31 و /32 در صورت پشتیبانی، IP نامعتبر، هم‌پوشانی و gateway خارج از subnet.
- لینک/رسانه: ورودی‌های مرزی و واحدها.
